Publish

Save changes never wipes the feed — it keeps every entry and only adds new rows + applies your edits (value, type, labels, confidence). To drop specific entries, tick their checkboxes and hit Purge selected, or use the × on a row; Purge all wipes the entire feed in one click (community intel from pullers included).

Community sources

Pull STIX intel from community sources into the feed. Configure them under otx: and taxii_pullers: in config.yaml. "Pull now" runs a one-shot fetch (works even when a puller is disabled) — new objects appear in the feed and are gated like any community intel.

Import CSV / Excel (GT team)

Upload a CSV or .xlsx with any headers — fuzzy-mapped automatically: IP_Address / src_ip / Destination → IPv4/IPv6, domain / hostname / fqdn → domain, md5 / sha1 / sha256 / sha512 → file hash, indicator / value → URL, email, or free text, plus optional label(s) and confidence columns. Imports append to the manual feed (does not wipe existing rows). New here? Download the sample CSV, edit the values, and upload it back.

API keys

Scoped credentials for TAXII consumers. Use the prefix as the username and the key as the password (curl -u <prefix>:<key>), or paste them into the client's HTTP Basic fields — a key scoped to gt_intel can list and read only that collection. The secret is shown once, at creation: it is stored only as a hash and cannot be retrieved later. Revoking is permanent.
